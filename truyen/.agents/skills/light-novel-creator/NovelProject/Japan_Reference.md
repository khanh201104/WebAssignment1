# 日本现实基底研究 — 世界观构建参考

> 为「半魔幻架空超自然都市」提供现实锚点。2010-2050 时间跨度，覆盖铁道/企业/校园/城建。

---

## 一、铁道与交通

### 1.1 铁道分类体系

| 类别 | 日文 | 特征 | 追加料金 |
|------|------|------|----------|
| 普通 | 各駅停車 | 站站停 | 无 |
| 快速 | 快速 | 跳部分站，同价 | 无 |
| 急行 | 急行 | 跳更多站 | 部分有 |
| 特急 | 特急 | 仅停主要站 | 500-4000円 |
| 新幹線 | 新幹線 | 独立轨道/站台 | 800-8000円 |

**创作要点**：
- 急行/特急的停站差异 = 角色"错过站"或"坐错车"的日常喜剧素材
- 終電（末班车）≈ 深夜 0:00-0:30 = 经典"留下还是回去"场景
- 女性専用車両（女性专用车厢）存在 → 男性角色误入的喜剧
- 通勤ラッシュ（早高峰 7:30-9:00）— 満員電車的窒息体验

### 1.2 主要运营者

**JR 集团**（1987 国铁分割民营化）：
- JR 東日本 — 首都圈/东北/信越
- JR 西日本 — 关西/中国/北陆
- JR 東海 — 东海道新幹線 + 名古屋圈
- JR 九州 / JR 北海道 / JR 四国

**大手私鉄（首都圈）**：
- 東急（田园都市线 → 渋谷）
- 西武（池袋线/新宿线）
- 京王（井の頭線 → 吉祥寺）
- 小田急（江ノ島/箱根方向）
- 京成（成田空港线）
- 東武（日光/川越方向）

**大手私鉄（关西圈）**：
- 阪急（神戸/宝塚/京都线）
- 阪神（大阪-神户）
- 近鉄（大阪-奈良-名古屋）
- 京阪（大阪-京都）
- 南海（关西空港/高野山）

### 1.3 IC 卡生态圈

- Suica（JR東日本）/ PASMO（私鉄/地下鉄共通）— 首都圈
- ICOCA（JR西日本）/ PiTaPa — 关西圈
- 2013 年全国互通完成 — 一张卡走遍日本
- **创作素材**：Suica 的"西瓜"昵称、改札機的ピッ音、残高不足的焦急

### 1.4 駅前商业模型

日本城市以**车站为中心**辐射发展：
- 駅ビル（车站大厦）— 百货/餐饮/办公一体
- 駅前商店街 — 传统商业街（近年衰退）
- ターミナル駅（枢纽站）— 渋谷/新宿/池袋/東京/品川/横浜/大阪/梅田/京都
- **创作要点**：駅前 = 约会碰头默认地点（「改札出たところで待ち合わせ」）

## 二、企业与资本

### 2.1 就职体系

**新卒一括採用**（应届生统一录用）：
- 大学 3 年级 3 月开始「就活」（就职活动）
- リクルートスーツ（黑色西装）统一着装
- 説明会 → エントリーシート → 筆記試験 → 面接（3-4轮）→ 内定
- 内定式（10月）→ 入社式（4月1日）
- **创作要点**：就活 = 人生分水岭，黑西装海洋的视觉冲击

### 2.2 雇佣形态

| 形态 | 特征 |
|------|------|
| 正社員 | 终身雇用（衰退中）、福利完整 |
| 契約社員 | 有期合同、更新与否的焦虑 |
| 派遣社員 | 通过派遣公司、最弱保障 |
| アルバイト/パート | 时薪制、学生/主妇为主 |

**2010-2050 趋势**：终身雇用瓦解、転職（跳槽）正常化、フリーランス增加

### 2.3 财阀·系列

旧财阀 → 战后解体 → 系列（Keiretsu）重建：
- **三菱グループ**：三菱商事、三菱UFJ銀行、三菱重工、三菱電機
- **三井グループ**：三井物産、三井住友銀行、三井不動産
- **住友グループ**：住友商事、三井住友銀行、住友化学

综合商社（総合商社）：三菱商事、三井物産、伊藤忠商事、丸紅、住友商事

**创作要点**：
- 金曜会（三菱）/ 二木会（三井）/ 白水会（住友）— 定期密会
- 系列内企业的"相互持股"形成隐形权力网络
- 「財閥系」角色 = 天生资源丰富但背负家族期待

### 2.4 黑色企业现象

- ブラック企業：過労死线（月80h+残業）、サービス残業（无偿加班）、パワハラ
- 過労死（Karoshi）— 年认定数百件
- 社畜（Shachiku）— 会社の家畜的缩写 → 2010s 流行语
- **创作要点**：大企业 vs 黑色企业 vs ベンチャー（初创）的三极格局

### 2.5 飲み会文化

- 一次会（居酒屋）→ 二次会（バー/カラオケ）→ 三次会（深夜）
- 付き合い（强制性社交）→ 断れない空気
- 乾杯时上司先、新人负责注酒
- **创作要点**：飲み会 = 办公室政治泄露 / 角色关系推动器

## 三、校园制度

### 3.1 学年体系

```
4月 入学式・始業式
 1学期（4月-7月）→ 夏休み（7月下旬-8月）
2学期（9月-12月）→ 冬休み（12月下旬-1月初）
3学期（1月-3月）→ 春休み（3月下旬-4月初）
3月 卒業式
```

- 小学校 6年 → 中学校 3年（義務教育）→ 高校 3年 → 大学 4年
- 高校分类：全日制（主流）/ 定時制（夜间）/ 通信制（函授）
- 学科：普通科（升学主流）/ 工業科/商業科/農業科/国際科

### 3.2 受験制度

**偏差値**：全国模試中排名 → 学校固有偏差値门槛
- 70+：東大・京大・早慶上位学部
- 60-65：GMARCH・関関同立
- 50-55：日東駒専・産近甲龍
- <50：Fラン（底层）

**受験战争节点**：
- 中学受験（小6）：私立/国立中学入試
- 高校受験（中3）：公立/私立高校入試
- 大学受験（高3）：センター試験 → 個別試験

**创作要点**：
- 塾（cram school）通い = 角色的放学后生活
- 偏差値 = 社交标签、鄙视链
- 浪人（高考失利复读） = 常见且正常的身份

### 3.3 部活（社团）

- 运动系 vs 文化系
- 強豪校（体育名門）部活 = 每天 3h+、周末合宿、上下関係严格
- 文化系：吹奏楽/美術/茶道/漫画研究/軽音楽/放送
- 夏の全国大会（甲子園/インターハイ/吹奏楽コンクール）
- 引退（三年级最后一个大赛后退出）— 青春定番

### 3.4 行事

| 行事 | 时期 | 特征 |
|------|------|------|
| 入学式 | 4月 | 桜の下 |
| 体育祭 | 5-6月/9-10月 | 騎馬戦/棒倒し/応援合戦/フォークダンス |
| 文化祭 | 9-11月 | クラス出店（メイド喫茶/お化け屋敷/焼きそば）、後夜祭 |
| 修学旅行 | 高2 | 京都/沖縄/北海道/海外 |
| 球技大会 | 学期末 | 班级对抗 |
| 卒業式 | 3月 | 第二ボタン（第二颗纽扣 = 告白） |

### 3.5 学生组织

**生徒会**（学生会）：
- 会長 / 副会長 / 書記 / 会計 / 庶務
- 選挙管理委員会
- 文化祭実行委員会（独立于生徒会的临时组织）

**委員会**：図書/保健/風紀/美化/放送/新聞/体育/給食（小学）

**创作要点**：
- 風紀委員 = 天然的反派/监管者角色
- 図書委員 = 安静独处的场景天然发生地
- 生徒会長 = 全校 idol 的经典人设

### 3.6 制服

- 男子：学ラン（詰襟）/ ブレザー
- 女子：セーラー服 / ブレザー / ワンピース型
- ローファー（皮鞋）/ 指定通学靴下
- スカート丈（裙子长度）— 校规 vs 私服打架线
- 夏服/冬服切换（衣替え）— 6月/10月

## 四、都市与地域

### 4.1 行政体系

```
日本 → 47 都道府県
  ├─ 東京都（1都）
  ├─ 北海道（1道）
  ├─ 大阪府/京都府（2府）
  └─ 43県
       └─ 市町村
            ├─ 政令指定都市（人口50万+、20个）
            └─ 特別区（东京23区）
```

### 4.3 首都圈 vs 关西圈

| 方面 | 首都圈 | 关西圈 |
|------|--------|--------|
| 语言 | 標準語 | 関西弁（大阪/京都/神户各有差异） |
| 駅のエスカレーター | 左立ち（左站右行） | 右立ち（右站左行） |
| 人际关系 | ドライ（趋冷） | ウェット（趋热） |
| 電車 | 無言が基本 | 会話可 |

### 4.4 住房

- マンション = 中高层公寓（分譲/賃貸）
- アパート = 木造/軽量鉄骨 2-3 层（賃貸为主）
- 一戸建て = 独栋住宅（郊区/地方）
- 団地 = 公団住宅（老式社区、人口老龄化）
- 1K/1DK/1LDK/2LDK/3LDK → 间数·客厅·餐厅·厨房

### 4.5 便利店社会

- セブンイレブン（7-Eleven）/ ローソン（Lawson）/ ファミリーマート（FamilyMart）
- 三大便利店覆盖 5 万+ 店 → 任何地方步行 5 分钟必有
- 服务：ATM/快递/复印/公共料金支付/チケット発券/トイレ
- **创作要点**：便利店 = 24h 不灭的安全灯 / 深夜偶遇的舞台 / バイト的标准选择

### 4.6 特区制度（自治城邦的现実锚点）

日本实际存在的**国家戦略特区**体系：
- 東京圏、関西圏、新潟市、養父市、福岡市、沖縄県 等
- 特区可获得：規制緩和（放松规制）、税制優遇、外国人材受入拡大
- **创作衔接点**：将特区概念放大 → 半自治的私立学园都市/企业城邦

## 五、创作衔接：从现实到半魔幻

### 5.1 可魔改的点

| 现实要素 | 半魔幻化方向 |
|----------|--------------|
| JR/私鉄 | 异世界連接駅、幽灵电车、時間差线路 |
| 財閥/系列 | 魔法資源垄断家族、超能力血统管理 |
| 偏差値 | 魔力測定値、戦闘力ランキング |
| 部活 | 超能力部/魔術研究会/対怪異委員会 |
| 特区 | 私立自治学園都市（多 IP 角色共存） |
| Suica | 魔力ポイントカード、領域通行証 |
| 終電 | 深夜の境界線——終電後进入"裏世界" |

### 5.2 多 IP 联动合理性

- 特区学園都市 = 不同作品/世界观角色的共存容器
- 各校/各区对应不同"勢力圈"或"IP 势力"
- 財閥系 = 跨作品的经济命脉连接点
- 鉄道網 = 物理移动 + 異世界移動的双重功能
